📘 Project 2: Pattern Generator and Number Analyzer
📌 Introduction

  This is my second Python project.
  It is a simple menu-driven program made using Python.
  
  The program can:
  
  •Generate a star pattern
    Prints a triangle star pattern based on user input.
  •Analyze numbers in a range
    ->Check even and odd numbers
    ->Find the sum of numbers
  •Exit the program
